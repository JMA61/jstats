# Internal helper: a variable's one value, as a message shows it

A labelled code with its label ("1: Yes"), a text value as it is (a
blank cell as `<blank>`), anything else as R prints it.

## Usage

``` r
.jst_one_value_text(x)
```

## Arguments

- x:

  The variable; its first non-missing value is shown.

## Value

Character(1).
