# Internal helper: a chart's scales, added in a look's colors

Internal helper: a chart's scales, added in a look's colors

## Usage

``` r
.jst_plot_add_scales(p, scales, look)
```

## Arguments

- p:

  The ggplot.

- scales:

  A list of list(aes, levels, guide).

- look:

  A look.

## Value

The ggplot.
