# Internal helper: set the look of the chart being drawn

Internal helper: set the look of the chart being drawn

## Usage

``` r
.jst_plot_look_set(look)
```

## Arguments

- look:

  A look
  ([`.jst_plot_look()`](https://jma61.github.io/jstats/reference/dot-jst_plot_look.md)),
  or NULL to clear it.

## Value

The look that was set before, invisibly, for
[`.jst_plot_look_restore()`](https://jma61.github.io/jstats/reference/dot-jst_plot_look_restore.md).
