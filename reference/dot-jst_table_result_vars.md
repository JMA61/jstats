# Internal helper: the variables of a result that headings = and markers = may name

A descriptives or frequency result's variables; a model's predictors –
each term as the coefficient table keys it, a dummy-coded variable by
its own name (the intercept aside); a correlation's variables; a t
test's or an ANOVA's outcome; a crosstab's row variable; a scale's
items.

## Usage

``` r
.jst_table_result_vars(r)
```

## Arguments

- r:

  A result.

## Value

Character, possibly empty.
