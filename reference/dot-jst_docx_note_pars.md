# Internal helper: the note paragraphs of a table

Internal helper: the note paragraphs of a table

## Usage

``` r
.jst_docx_note_pars(tbl, style, keep_next = FALSE)
```

## Arguments

- tbl:

  A jst_table.

- style:

  The style list.

- keep_next:

  Logical; for a note inside a row.

## Value

Character; one paragraph per note line.
