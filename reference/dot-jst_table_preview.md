# Internal helper: print a table structure to the console

Internal helper: print a table structure to the console

## Usage

``` r
.jst_table_preview(tbl, style, number = 1L)
```

## Arguments

- tbl:

  A jst_table.

- style:

  The style list.

- number:

  The table's number for the caption; 1 for a table on its own.
