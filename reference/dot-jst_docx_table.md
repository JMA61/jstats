# Internal helper: the table of a jst_table, as XML

Internal helper: the table of a jst_table, as XML

## Usage

``` r
.jst_docx_table(tbl, style, number, widths)
```

## Arguments

- tbl:

  A jst_table.

- style:

  The style list.

- number:

  The table's number (for a caption row).

- widths:

  Column widths in dxa.

## Value

Character(1); the w:tbl element.
