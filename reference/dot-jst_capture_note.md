# Internal helper: keep a note in its place among the output

Internal helper: keep a note in its place among the output

## Usage

``` r
.jst_capture_note(ctx, text)
```

## Arguments

- ctx:

  A scope's context.

- text:

  The message's text, as conditionMessage() gives it (its closing
  newline included).

## Value

`ctx`, invisibly.
