# Internal: a name in numeric =, categorical = or count = that the call's variables do not include

jdesc(), jcorr(), both forms of jplot(), and jlm() and jlogistic()
(Session 392, the (S282) item: the word "argument" left runtime text by
voice Rule B's S355 form, the input named with its "="). Each had said
"numeric argument: 'x' not found among ...", the names joined by commas.

## Usage

``` r
.jst_not_among_text(arg, bad, among)
```

## Arguments

- arg:

  Character(1). "numeric", "categorical" or "count".

- bad:

  Character. The names not found.

- among:

  Character(1). What they are not among: "the variables given to
  jdesc()", "the independent variables in d".

## Value

Character(1).
