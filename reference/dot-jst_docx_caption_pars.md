# Internal helper: the caption paragraphs of a table

Internal helper: the caption paragraphs of a table

## Usage

``` r
.jst_docx_caption_pars(tbl, style, number)
```

## Arguments

- tbl:

  A jst_table.

- style:

  The style list.

- number:

  The table's number.

## Value

Character; one or two paragraphs' XML.
