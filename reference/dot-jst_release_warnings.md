# Internal helper: give back the warnings a read held

Internal helper: give back the warnings a read held

## Usage

``` r
.jst_release_warnings(held)
```

## Arguments

- held:

  A list of warning conditions, from
  [`.jst_read_held()`](https://jma61.github.io/jstats/reference/dot-jst_read_held.md);
  NULL for none.

## Value

Invisible NULL.
