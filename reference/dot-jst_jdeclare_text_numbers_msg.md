# Internal helper: the stop for numbers given as a text variable's codes

Internal helper: the stop for numbers given as a text variable's codes

## Usage

``` r
.jst_jdeclare_text_numbers_msg(vars, data_name, line)
```

## Arguments

- vars:

  The text variable(s).

- data_name:

  Unused; kept for the call sites' symmetry.

- line:

  The line to run
  ([`.jst_jdeclare_text_quoted_line()`](https://jma61.github.io/jstats/reference/dot-jst_jdeclare_text_quoted_line.md)).

## Value

Character(1), the message.
