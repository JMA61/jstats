# Internal helper: is it a set of charts?

What jplot() returns for a result it draws several plots of – a plain
list, every element a chart – which jtable() takes in place, each chart
a figure of its own (Session 415).

## Usage

``` r
.jst_is_chart_set(x)
```

## Arguments

- x:

  Anything.

## Value

Logical(1).
