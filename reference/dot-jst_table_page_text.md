# Internal helper: a table's page, in a few words

The orientation, then what the fit did: the text stepped down to fit the
page, long labels wrapped onto two lines.

## Usage

``` r
.jst_table_page_text(tbl, L)
```

## Arguments

- tbl:

  A jst_table.

- L:

  Its layout (one element of
  [`.jst_docx_layout()`](https://jma61.github.io/jstats/reference/dot-jst_docx_layout.md)).

## Value

Character(1), e.g. "on a landscape page, its text at 10 pt".
