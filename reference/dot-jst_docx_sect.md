# Internal helper: a section's properties

The page size, turned for landscape, and the margins.

## Usage

``` r
.jst_docx_sect(page, landscape)
```

## Arguments

- page:

  A page from
  [`.jst_docx_page()`](https://jma61.github.io/jstats/reference/dot-jst_docx_page.md).

- landscape:

  Logical(1).

## Value

Character(1), the w:sectPr element.
