# Internal helper: what a figure shows, in a few words

For jtable()'s report and the console preview: the kind of chart, "a bar
chart", "a scatterplot", "a model's residual plot"; "a chart drawn in
ggplot2" for one drawn by hand.

## Usage

``` r
.jst_figure_noun(fig)
```

## Arguments

- fig:

  A jst_figure.

## Value

Character(1).
