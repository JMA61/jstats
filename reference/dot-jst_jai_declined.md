# Internal helper: the declined-write note

After a declined CREATE the likely reason is the folder, so the note
says how to name another. After a declined REPLACE – an existing
AGENTS.md block, an existing SKILL.md – the likely reason is "not yet",
and the note says only that nothing was written (the S206 item,
candidate 3; Session 357).

## Usage

``` r
.jst_jai_declined(replace = FALSE)
```

## Arguments

- replace:

  Logical; TRUE when the declined write would have replaced something
  that exists.
