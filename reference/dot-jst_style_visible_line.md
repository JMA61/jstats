# Internal helper: the line that sets the visible style folder

`joptions(style.dir = "<Documents>/jstats styles")`, two spaces in, the
path's quotation marks escaped and the path whole on one line, so it
runs as printed: the last line of the jstats-folder note and of
jstyle()'s list when no style folder is set (Session 427; one home for
the two).

## Usage

``` r
.jst_style_visible_line(visible = .jst_style_visible_dir())
```

## Arguments

- visible:

  The folder
  ([`.jst_style_visible_dir()`](https://jma61.github.io/jstats/reference/dot-jst_style_visible_dir.md)).

## Value

Character(1).
