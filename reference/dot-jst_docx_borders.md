# Internal helper: the cell borders for one cell under the style's rules

Internal helper: the cell borders for one cell under the style's rules

## Usage

``` r
.jst_docx_borders(rules, top, bottom, left, right, color)
```

## Arguments

- rules:

  "apa", "grid", "outer" or "none".

- top, bottom, left, right:

  Logical; the cell's edges that the rule set draws when it draws that
  kind of edge.

- color:

  Hex colour.
