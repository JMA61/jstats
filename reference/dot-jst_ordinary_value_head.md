# Internal: a code the map also assigns as an ordinary value

The first sentence of jrecode() and jencode()'s stop; the second is
`.jst_txt_both_missing` (Session 383).

## Usage

``` r
.jst_ordinary_value_head(head, code, rules)
```

## Arguments

- head:

  Character(1). The sentence's opening, as the caller built it.

- code:

  Character(1). The code, formatted.

- rules:

  Character(1). The rules that assign it.

## Value

Character(1).
