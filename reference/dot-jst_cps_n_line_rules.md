# Table 4 (S284): which FORM the one-line N statement takes. Chosen by the layout's n_line_family and, for the pool family, whether the analysis variables' per-variable Ns differ. The excluded-count rider (appended whenever cases were excluded before the analysis) is orthogonal to the form and is applied by the renderer, not encoded here. The header family (Session 320, the screening layout) has the one form "none": the caller's own header states the N, so the renderer prints no line and returns the rider's count to the caller instead.
