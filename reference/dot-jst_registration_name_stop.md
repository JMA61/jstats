# Internal helper: the stop for a named clear whose name carries nothing

`jdummy(z, NULL)` where `z` is not a data frame and no dummy
registration is stored under that name (Session 342). The registration
verbs' form of
[`.jst_setting_name_stop()`](https://jma61.github.io/jstats/reference/dot-jst_setting_name_stop.md)'s
first message: the name is the subject (voice Rule AD) and takes no
article and no "data frame", since it is not one; "was not found" for a
name that did not evaluate and "is not a data frame" for one that holds
something else (Rule AH); the status call is the remedy.

## Usage

``` r
.jst_registration_name_stop(kind, st)
```

## Arguments

- kind:

  One of "numeric", "count", "likert", "dummy".

- st:

  The
  [`.jst_setting_name_state()`](https://jma61.github.io/jstats/reference/dot-jst_setting_name_state.md)
  result.

## Value

Does not return; stops.
