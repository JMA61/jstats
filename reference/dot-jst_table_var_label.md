# Internal helper: a variable's label, from a c(name = , label = ) pair

Internal helper: a variable's label, from a c(name = , label = ) pair

## Usage

``` r
.jst_table_var_label(a, fallback)
```

## Arguments

- a:

  The pair (a result's "outcome", "group" or "variable" attribute), or
  NULL.

- fallback:

  The name to use when there is no label.

## Value

Character(1).
