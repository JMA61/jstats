# Internal helper: the line after jrelabel(..., modify = TRUE)

"Value labels applied to Q1, Q2 and Q3 in d." (Session 378), at the
standard and full output levels; nothing when the call applied nothing.

## Usage

``` r
.jst_relabel_done(vars, data_name, values, variable)
```

## Arguments

- vars:

  Character; the variables labeled.

- data_name:

  Character(1).

- values, variable:

  Logical; value labels, a variable label applied.

## Value

Invisible NULL.
