# Internal: a map rule's new value the parsers do not take

The numeric and the text map parsers (Session 383).

## Usage

``` r
.jst_map_rhs_text(rhs, rule, one)
```

## Arguments

- rhs, rule:

  Character(1). The value and the rule as typed.

- one:

  Character(1). The marker form in force, from
  [`.jst_marker_syntax()`](https://jma61.github.io/jstats/reference/dot-jst_marker_syntax.md).

## Value

Character(1).
