# Internal: the stop for an outcome with no variation within any group

jt() and jaov() (Session 383).

## Usage

``` r
.jst_no_variation_stop(dv, group, test)
```

## Arguments

- dv, group:

  Character(1). The outcome and the grouping variable.

- test:

  Character(1). "A t-test" or "An ANOVA".

## Value

Does not return; stops.
