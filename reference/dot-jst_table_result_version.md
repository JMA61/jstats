# Internal helper: the version a result was made by, for a stop

Internal helper: the version a result was made by, for a stop

## Usage

``` r
.jst_table_result_version(x)
```

## Arguments

- x:

  A result.

## Value

Character(1): "jstats 0.9.200" from the stamp, or "an earlier version of
jstats" when there is none (a result made before the stamp).
