# Internal helper: the name a fetched element starts from

Internal helper: the name a fetched element starts from

## Usage

``` r
.jst_fetch_root(e)
```

## Arguments

- e:

  A symbol or a
  [`.jst_is_fetch()`](https://jma61.github.io/jstats/reference/dot-jst_is_fetch.md)
  call.

## Value

Character(1); "" for anything else.
