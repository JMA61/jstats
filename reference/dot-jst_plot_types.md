# Internal constant: the chart types of jplot()'s data-first forms

One list for the bare-word check, the check of `type =` and the stop
that names them. A scatterplot and a boxplot are drawn from a formula;
the rest from a data frame and its variables. The last three (Session
416; rulings R66 and R68) are drawn only when asked for.

## Usage

``` r
.jst_plot_types
```
