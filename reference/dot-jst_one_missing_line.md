# Internal: the line that maps several codes to one missing value

jrecode() and jencode()'s D1 notes (Session 383).

## Usage

``` r
.jst_one_missing_line(n, target)
```

## Arguments

- n:

  Integer. How many codes were flagged.

- target:

  Character(1). "missing", or a marker such as ".b".

## Value

Character(1).
