# Internal helper: the choices of a Rule A choice error

Each in double quotes, "or" before the last, an Oxford comma at three or
more and none at two, a full stop after:
[`.jst_stop_arg()`](https://jma61.github.io/jstats/reference/dot-jst_stop_arg.md)'s
list, in one home since Session 401 so the style settings' errors give
it too.

## Usage

``` r
.jst_choice_list(choices)
```

## Arguments

- choices:

  Character vector.

## Value

Character(1).
