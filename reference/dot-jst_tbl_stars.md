# Internal helper: the stars a p-value earns

Internal helper: the stars a p-value earns

## Usage

``` r
.jst_tbl_stars(p, stars = c(0.05, 0.01, 0.001))
```

## Arguments

- p:

  Numeric vector.

- stars:

  The thresholds, largest first; one star per threshold passed.

## Value

Character vector; "" for none or NA.
