# Internal helper: the glyph of the i-th specific-note mark

Internal helper: the glyph of the i-th specific-note mark

## Usage

``` r
.jst_tbl_mark(i, marks = "letters")
```

## Arguments

- i:

  Integer; the mark's position.

- marks:

  "letters" (a, b, c, ...) or "symbols" (dagger, double dagger, section
  sign, then doubled).
