# Internal helper: the head's sentence on the marks a text takes

The second of the two sentences both heads may carry (see
[`.jst_style_head_section_line()`](https://jma61.github.io/jstats/reference/dot-jst_style_head_section_line.md));
the complete copy's has it. It names the texts the writers set by the
light markup – a title, a single column's head, the note's and the
source's labels – as run at Session 419: a row's label (intercept.label)
and a spanner's (total.label) print the marks as typed.

## Usage

``` r
.jst_style_head_marks_line()
```

## Value

Character(1), a comment line.
