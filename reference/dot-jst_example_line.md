# Internal helper: the line ruling R22's and ruling R23's stops end on

The function's example on community, keeping the call's display options
whose values are constants (method =, digits = and the like), which hold
on any data (ruling R22, Session 369).

## Usage

``` r
.jst_example_line(ex, items = list(), cn = character(0))
```

## Arguments

- ex:

  The
  [`.jst_r22_example()`](https://jma61.github.io/jstats/reference/dot-jst_r22_example.md)
  entry.

- items, cn:

  The call's arguments as a list, and their names.

## Value

Character(1), the line, its assignment included.
