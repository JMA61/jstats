# Internal helper: the categories a predictor dummy-coded in the call holds

Counted as
[`.jst_make_dummy_names()`](https://jma61.github.io/jstats/reference/dot-jst_make_dummy_names.md)
counts them: the observed values, a factor's levels in use, a text
variable's blank cells as one category.

## Usage

``` r
.jst_n_categories(x)
```

## Arguments

- x:

  The variable, filtered.

## Value

Integer(1).
