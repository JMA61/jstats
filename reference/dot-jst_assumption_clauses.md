# Internal data: assumption-check warning clauses, keyed by call site

One entry per warning site. `verb` is "seems" (a structural hedge) or
"is" (asserted, definitive); `connector` joins the opener to the
consequence ("; " keeps one sentence at every site – ruling R40, Session
395: the hedge sites' ". " gave two sentences on one line); `clause` is
the analysis-specific consequence text. Editing wording here changes it
everywhere that site fires.

## Usage

``` r
.jst_assumption_clauses
```
