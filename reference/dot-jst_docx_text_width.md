# Internal helper: the width a text needs in a cell, in dxa

Internal helper: the width a text needs in a cell, in dxa

## Usage

``` r
.jst_docx_text_width(s, size, digits = FALSE)
```

## Arguments

- s:

  Character; the texts.

- size:

  Points.

- digits:

  Logical; TRUE for a number column (a digit is about half an em), FALSE
  for text (a letter a little less).
