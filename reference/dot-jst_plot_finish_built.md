# Internal helper: a data-first chart marked as jplot()'s

Internal helper: a data-first chart marked as jplot()'s

## Usage

``` r
.jst_plot_finish_built(p, type, n, frame, look)
```

## Arguments

- p:

  The builder's chart
  ([`.jst_plot_built()`](https://jma61.github.io/jstats/reference/dot-jst_plot_built.md)).

- type:

  The resolved chart type.

- n:

  The cases drawn.

- frame:

  The facts
  [`.jst_plot_frame_facts()`](https://jma61.github.io/jstats/reference/dot-jst_plot_frame_facts.md)
  read.

- look:

  The look it was drawn in.

## Value

The chart.
