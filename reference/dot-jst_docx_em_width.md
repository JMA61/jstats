# Internal helper: a text's width in ems, with a small allowance

Measured in the face `font` names
([`.jst_docx_font_widths()`](https://jma61.github.io/jstats/reference/dot-jst_docx_font_widths.md);
Session 407), Times New Roman when it names none.

## Usage

``` r
.jst_docx_em_width(x, font = NULL)
```

## Arguments

- x:

  Character(1).

- font:

  Character(1), or NULL.
