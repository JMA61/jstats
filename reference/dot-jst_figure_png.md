# Internal helper: a figure's picture as a PNG file's bytes

Internal helper: a figure's picture as a PNG file's bytes

## Usage

``` r
.jst_figure_png(fig, size, look = .jst_figure_look(fig))
```

## Arguments

- fig:

  A jst_figure.

- size:

  Its size
  ([`.jst_figure_size()`](https://jma61.github.io/jstats/reference/dot-jst_figure_size.md)).

- look:

  Its look.

## Value

A raw vector.
