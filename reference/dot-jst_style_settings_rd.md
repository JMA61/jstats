# Internal helper: the settings help page's sections

Generated from `.jst_style_spec` and `.jst_style_apa` when the help is
built (Session 402: "?jstyle_keys GENERATED from .jst_style_spec when
the help is built"; named jstyle_settings at Session 406), so the page
cannot drift from what jstats accepts: an example of the file's form,
then one section per part, each setting with what it does, what it takes
and apa's value. The text is plain ASCII: a Greek letter in a value is
written with `\eqn`, its name the text form.

## Usage

``` r
.jst_style_settings_rd()
```

## Value

Character: roxygen `@rawRd` tags.
