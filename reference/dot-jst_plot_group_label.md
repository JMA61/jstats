# Internal helper: a comparison's variable, as its plots title an axis

Internal helper: a comparison's variable, as its plots title an axis

## Usage

``` r
.jst_plot_group_label(x, which, name, wrap = TRUE)
```

## Arguments

- x:

  A `jst_ttest` or `jst_anova` result.

- which:

  "outcome" or "group".

- name:

  The variable's name.

- wrap:

  Logical(1).

## Value

Character(1): its label, the name where it has none.
