# Internal helper: one table cell

Internal helper: one table cell

## Usage

``` r
.jst_docx_cell(pars, width, borders, span = NULL, fill = NULL)
```

## Arguments

- pars:

  The paragraphs' XML, pasted.

- width:

  dxa.

- borders:

  The tcBorders XML.

- span:

  Grid span, or NULL.

- fill:

  Hex colour, or NULL.
