# Internal helper: the lines of a full style file

Every setting of every part, each after a line saying what it does and
one saying what it takes (Session 406), the two stamps and based.on at
the top: the file jstyle(save.as =) writes when it is given no settings.
The header says to change values only, so the file can be handed to a
person or an AI assistant with a request: the file's name on a line of
its own, then one sentence a line, none wrapped (Session 407), and since
Session 409 a block for an assistant asked to match an example – since
Session 420 naming the file to return, name.jstyle. based.on names the
built-in the copied style reaches first: report for a copy of report or
of a file based on it, else apa. A blank line follows each part's
heading note and each setting, none between a setting's notes and the
setting (Session 410;
[`.jst_style_blank_lines()`](https://jma61.github.io/jstats/reference/dot-jst_style_blank_lines.md)).

## Usage

``` r
.jst_style_file_lines(st, name)
```

## Arguments

- st:

  The style copied.

- name:

  The new file's style name.
