# Internal: the stop for a jdesc() or jfreq() result given to jplot()

Internal: the stop for a jdesc() or jfreq() result given to jplot()

## Usage

``` r
.jst_plot_result_stop(cls, ...)
```

## Arguments

- cls:

  Character(1). "jst_desc" or "jst_freq".

- ...:

  The example lines, each indented and ending in a newline but the last.

## Value

Does not return; stops.
