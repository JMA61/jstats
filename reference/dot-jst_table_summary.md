# Internal helper: what a table holds, for jtable()'s report

Internal helper: what a table holds, for jtable()'s report

## Usage

``` r
.jst_table_summary(results, type, headings = NULL)
```

## Arguments

- results:

  The results the table was built from.

- type:

  Its table type.

- headings:

  The headings given, or NULL.

## Value

Character(1), e.g. "4 models side by side".
